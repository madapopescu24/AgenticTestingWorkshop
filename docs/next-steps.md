# 🚀 Next Steps

!!! tip "You've reached the end of the workshop"

    You've gone from setting up the `uip` CLI to taking a design document to requirements, test cases, and an executed, reported test set in Test Cloud, with a coding agent doing the build work alongside you.

## 🔁 Keep testing

- Run the same three labs against your own application: swap the design document and keep the prompts.
- Add negative test cases, such as a transfer larger than the balance or an invalid loan term, and add them to your test set.
