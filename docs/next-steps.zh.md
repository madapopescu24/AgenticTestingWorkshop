# 🚀 后续步骤 { #next-steps }

!!! tip "你已完成本次工作坊"

    你从设置 `uip` CLI 开始，一路把设计文档变成了需求、测试用例，以及在 Test Cloud 中已执行并生成报告的测试集，整个过程中都有编码智能体与你一起完成构建工作。

## 🔁 继续测试 { #keep-testing }

- 针对你自己的应用运行同样的三个实验：换掉设计文档，保留提示词。
- 添加反向测试用例，例如转账金额大于余额或贷款期限无效，并把它们加入你的测试集。
- 把更多测试用例改为数据驱动，让一个测试用例用多组值运行。
- 用同样的 UiPath skills 试试其他编码智能体（Cursor、Codex）。
