    From one design document to requirements, test cases, test sets, and executions, with Autopilot and a coding agent. With two breaks and lunch.

    The hands-on part starts right after the intro, with Setup: you get your VM, your sign-in, and your tenant ready together.

    Sign in to the training environment with your workshop account Hands-on

    Confirm the tenant in Studio Web Hands-on

    Connect Studio to the training tenant, and check the Autopilot panel Hands-on

    Register your UiBank test user and create your credential asset Hands-on

    Create a new project in Test Manager (for example, project name {YourName}_UIB_Test, and a unique prefix of your own, such as your initials plus a digit) Hands-on

    Create a new test automation project in Studio and connect it to Test Manager Hands-on

    Open Studio and Test Manager, and ask Autopilot in Studio Desktop to create the requirements from the .docx Hands-on

    Discuss the resulting requirements in Test Manager Discussion

    Evaluate the quality of the requirements with Autopilot in Test Manager, implement some suggestions, then re-evaluate Hands-on

    How the day holds up

    • The plan is flexible. We can adapt it during the workshop, including the breaks.
    • Agents' build time is your review time. While Autopilot or your coding agent works, read what it's producing, or read ahead in the next tab.
    • The breaks are catch-up time too. If your coding agent is still building when the break starts, let it carry on while you step away.
    • Test sets have a fallback. The trainer publishes the DemoUiBankTests package in the shared folder. If your own test cases aren't automated in time, use the trainer's when you create and run test sets — you still run a test set and read its executions.
