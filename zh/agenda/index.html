    议程

    🗓️ 议程¶

    从一份设计文档出发，借助 Autopilot 和编码智能体，依次得到需求、测试用例、测试集和执行。中间有两次休息和午餐。

    👋 欢迎¶

    👋 欢迎、自我介绍，以及今天的安排 演示讲解

    💡 1. 简介 + 理论知识¶

    💡 简介 + 理论知识：UiPath Test Cloud 和 Test Manager、Autopilot for Testers、Autopilot for Developers、使用 uip CLI 和 UiPath 技能的编码智能体，以及何时使用哪一种 演示讲解

    🙌 2. 动手实践¶

    动手实践部分紧接在简介之后，从环境准备开始：大家一起准备好虚拟机、登录账号和租户。

    ⚙️ 环境准备¶

    使用你的工作坊账号登录培训环境 动手实践

    在 Studio Web 中确认租户 动手实践

    将 Studio 连接到培训租户，并检查 Autopilot 面板 动手实践

    注册你的 UiBank 测试用户，并创建凭据资产 动手实践

    下载设计文档到你的工作坊文件夹 动手实践

    在 Test Manager 中创建新项目（例如项目名称 {YourName}_UIB_Test，以及一个你自己独有的前缀，比如姓名首字母加一个数字） 动手实践

    在 Studio 中创建新的测试自动化项目，并将其连接到 Test Manager 动手实践

    📋 需求¶

    打开 Studio 和 Test Manager，让 Autopilot in Studio Desktop 创建需求，来源为 .docx 文件 动手实践

    在 Test Manager 中讨论生成的需求 讨论

    用 Test Manager 中的 Autopilot 评估需求质量，采纳部分建议，然后重新评估 动手实践

    ☕ 休息¶

    🧪 测试用例¶

    让 Test Manager 中的 Autopilot 创建测试用例，针对某一条具体需求 动手实践

    🍽️ 午餐¶

    离开屏幕休息一下。如果你的编码智能体还在构建，就让它在你吃饭时继续运行。

    🙌 2. 动手实践（续）¶

    🧪 测试用例（续）¶

    在 Studio 中手动实现 Login 测试用例 动手实践

    在 Studio Desktop 中让 Autopilot in Studio Desktop 或 Codex 生成一个测试用例 动手实践

    在 Test Manager 中自主运行一个测试用例，并实时观看 动手实践

    再实现几个测试用例 动手实践

    ☕ 休息¶

    ▶️ 执行¶

    在 Test Manager 中浏览 Executions 选项卡 动手实践

    📦 测试集¶

    将你的测试项目发布到租户 feed 动手实践

    让 Autopilot in Studio Desktop 根据测试用例创建测试集 动手实践

    运行测试集 动手实践

    查看测试集的执行 动手实践

    告诉我们哪些地方效果好，哪些地方需要改进。

    今天的安排如何进行

    • 计划是灵活的。 我们可以在工作坊期间调整安排，包括休息时间。
    • 智能体构建的时间就是你审阅的时间。 当 Autopilot 或你的编码智能体在工作时，看看它正在生成什么，或者提前阅读下一个选项卡。
    • 休息时间也可以用来追赶进度。 如果休息开始时你的编码智能体还在构建，就让它继续运行，你先去休息。
    • 测试集有备用方案。 讲师会在共享文件夹中发布 DemoUiBankTests 包。如果你自己的测试用例没能及时完成自动化，在创建和运行测试集时使用讲师的包即可——你仍然会运行一个测试集并查看它的执行。
